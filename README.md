# Projeto Diário

Crie um sistema de gestão de projetos de implantação com três áreas principais: 1. Cronograma de projeto com gerenciamento de etapas, datas e status; 2. Mapa/painel com informações e status dos módulos homologados; 3. Diário de bordo para registro de ocorrências, tópicos abordados e observações de cada sessão de treinamento.
